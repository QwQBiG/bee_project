# 原始视频接入流程

本流程适用于只有视频、没有检测框和行为标注的数据。原始视频不应直接提交到 Git 仓库。

## 1. 建立视频清单

只读取视频元数据和哈希，不抽帧：

```powershell
python tools/prepare_unlabeled_dataset.py `
  "<官方数据目录>" `
  ".\datasets\official_work" `
  --frames-per-video 120
```

输出：

```text
datasets/official_work/dataset_manifest.json
```

自动识别不确定的场景会标记为 `unknown`；数据划分默认标记为 `unassigned`。必须人工确认场景和同源视频分组后，才能设置 `train`、`val`、`test`。

## 2. 抽取候选帧

确认清单后执行：

```powershell
python tools/prepare_unlabeled_dataset.py `
  "<官方数据目录>" `
  ".\datasets\official_work" `
  --frames-per-video 120 `
  --extract
```

需要安装 `opencv-python`。输出图片位于：

```text
datasets/official_work/frames/<video_id>/
```

## 3. 生成检测预标注

巢外和巢内应分别使用对应权重，输出到不同目录：

```powershell
python tools/prelabel_yolo.py `
  ".\datasets\official_work\dataset_manifest.json" `
  ".\datasets\official_work\frames" `
  ".\artifacts\models\hive_entrance_bee_yolov8n.pt" `
  ".\datasets\official_work\prelabels_outside" `
  --device cuda:0
```

预标注实例统一写为 `source: prediction`，必须人工校正为 `source: manual` 后才能进入金标准集。

## 4. 校验人工标注

```powershell
python tools/validate_annotations.py `
  ".\datasets\official_work\annotations" `
  --gold `
  --report ".\datasets\official_work\validation_report.json"
```

返回码：

- `0`：全部通过；
- `1`：发现非法标注或非人工实例；
- `2`：路径或文件格式错误。

## 5. 导出 YOLO Pose 数据

人工完成整蜂框和 `head`、`thorax`、`abdomen_tip` 后：

```powershell
python tools/export_yolo_pose.py `
  ".\datasets\official_work\annotations" `
  ".\datasets\official_work\frames" `
  ".\datasets\official_pose"
```

输出包含 `images/`、`labels/` 和 `data.yaml`，可用于 YOLO Pose 训练。

## 6. 评测头尾与朝向

```powershell
python tools/evaluate_pose.py `
  ".\datasets\official_work\gold\video-001.json" `
  ".\datasets\official_work\predictions\video-001.json" `
  --iou 0.5 `
  --pck 0.1 `
  --output ".\reports\pose_metrics.json"
```

主要结果包括 PCK、归一化关键点误差、平均朝向误差和头尾反转率。

## 7. 评测进出事件

```powershell
python tools/evaluate_entrance_events.py `
  ".\datasets\official_work\gold\video-001.json" `
  ".\datasets\official_work\predictions\video-001.json" `
  --tolerance-frames 5 `
  --output ".\reports\entrance_event_metrics.json"
```

主要结果包括进巢/出巢 Precision、Recall、F1 和计数绝对误差。

## 8. 数据安全

- `raw`、抽帧图片和模型权重不直接提交到 Git；
- 可提交不含受限原始内容的脚本、规范和小型统计报告；
- 每个标注文件保留视频 SHA-256、视频 ID 和原始帧号；
- 修改数据划分后重新执行校验，防止同源片段跨集合泄漏。
