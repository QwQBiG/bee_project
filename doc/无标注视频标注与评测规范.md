# 无标注蜜蜂视频的标注与评测规范

## 1. 目标

将巢内红外和巢外入口原始视频转换为可训练、可复核、可量化评测的数据。模型预测只用于预标注，人工确认的数据才可进入金标准测试集。

## 2. 数据分层

```text
raw/          原始视频，只读保存
manifests/    视频哈希、分辨率、帧率、场景和数据划分
frames/       从原始视频抽取的候选帧
annotations/  统一 JSON 标注
exports/      YOLO Detect、YOLO Pose、MOT 等训练格式
```

训练集、验证集和测试集必须按原始视频划分。不得把同一视频的相邻帧分到不同集合。

## 3. 实例标注

每只可辨认蜜蜂使用一个紧贴身体的整蜂框，格式为 `[x, y, width, height]`，单位为像素。

基础类别：

- `bee`：无法可靠细分或普通蜜蜂；
- `worker_bee`：能够由画面可靠确认的工蜂；
- `drone_bee`：能够可靠确认的雄蜂；
- `queen_bee`：能够可靠确认的蜂王；
- `pollen_bee`：能够清楚观察到花粉团；
- `varroa_mite`：能够清楚观察到瓦螨。

不清楚时使用 `bee`，不根据模型输出强行细分。

实例来源：

- `manual`：人工逐项确认；
- `prediction`：模型自动生成，必须包含置信度；
- `interpolated`：标注工具插值生成，必须人工抽查。

## 4. 头尾与姿态标注

每只适合进行姿态判断的蜜蜂标注三个关键点：

1. `head`：头部中心；
2. `thorax`：胸部中心；
3. `abdomen_tip`：腹部末端。

可见性：

- `0`：未标注或无法判断；
- `1`：被遮挡，但可根据相邻帧合理定位；
- `2`：清晰可见。

身体轴线由 `abdomen_tip → head` 定义。关键点不足时，朝向必须输出为未知，不能使用运动方向替代身体朝向。

## 5. 连续跟踪标注

同一短片段内，同一只连续可见蜜蜂使用相同 `track_id`。发生完全遮挡且无法确认身份时，应结束旧轨迹并分配新 ID，不能猜测身份。

跨视频、跨摄像头或离开画面后重新出现的蜜蜂，不默认具有同一 ID。长期个体识别需要标记、RFID 或经过独立评测的重识别模型。

## 6. 进出巢事件标注

巢门需要标定外侧、缓冲区和内侧。确认事件：

- `entering`：轨迹按“外侧→缓冲区→内侧”完成穿越；
- `leaving`：轨迹按“内侧→缓冲区→外侧”完成穿越；
- `uncertain`：目标在缓冲区消失、严重遮挡或方向无法确认。

每个事件记录 `track_id`、开始帧、穿越帧、结束帧和复核状态。仅进入缓冲区后原路返回的轨迹不计数。

## 7. 行为片段标注

行为使用连续帧范围，而不是单帧类别。第一批建议标签：

- `pollen_loaded_candidate`；
- `orientation_flight_candidate`；
- `waggle_dance_candidate`；
- `round_dance_candidate`；
- `defense_candidate`；
- `abnormal_posture_candidate`；
- `falling_candidate`；
- `stationary_candidate`。

带 `candidate` 的结果表示待生物学专家复核，不等同于病害、死亡或其他确定结论。

## 8. 质量控制

- 金标准集不得包含 `prediction`；
- 抽取至少一部分标注由第二人独立复核；
- 遮挡、模糊、密集和边缘目标均应纳入测试集；
- 修订标签定义后必须更新版本号，并记录受影响文件；
- 所有结果保留原视频哈希和帧号，确保能够回溯。

## 9. 评测指标

| 层级 | 指标 |
|---|---|
| 检测 | Precision、Recall、mAP50、mAP50-95 |
| 头尾姿态 | PCK/OKS、平均角度误差、头尾反转率 |
| 跟踪 | IDF1、HOTA、ID Switch、轨迹完整率 |
| 进出事件 | Precision、Recall、F1、计数绝对误差、重复计数率 |
| 生物学统计 | 与人工统计的 MAE、相对误差、时间序列相关性 |

## 10. 推荐流程

```text
视频清单 → 均匀抽帧 → 现有模型预标注 → 人工校正
→ 小型金标准集 → 首轮训练/评测 → 挑选困难样本
→ 补标 → 再训练 → 固定测试集复评
```

清理旧代码和旧数据只能在新模块通过固定测试集回归后进行，并使用独立提交保留回滚能力。
