# 智慧养蜂蜜蜂识别与行为量化研究项目

## 项目简介

本项目针对智慧养蜂场景，实现巢内外蜜蜂个体识别与行为智能量化分析。系统支持：
- 巢外场景：基于可见光视频的蜜蜂检测与持续跟踪
- 巢内场景：基于红外视频的蜜蜂识别、跟踪与姿态建模
- 行为量化：个体行为分类、群体活动分析、异常检测

## 安装步骤

### 1. 克隆或下载项目

```bash
cd bee_project
```

### 2. 创建虚拟环境（推荐）


### 3. 安装依赖库


## 项目配置

### 配置文件位置
`configs/config.yaml`

### 主要配置项说明

```yaml
# 模型配置
model:
  outside_detector:
    model_type: "yolov8"      # 检测模型类型
    model_size: "m"           # 模型大小: n/s/m/l/x
    conf_threshold: 0.25      # 置信度阈值
    iou_threshold: 0.45        # IoU阈值
    device: "cuda:0"          # 运行设备
  
  tracker:
    type: "botsort"              # 巢外默认准确性优先；可选 bytetrack
    max_age: 30               # 最大丢失帧数
    min_confidence: 0.3       # 最小置信度

# 数据配置
data:
  outside:
    video_path: "data/outside_hive"
    annotation_path: "datasets/outside_annotations"
  inside:
    video_path: "data/inside_hive"
    annotation_path: "datasets/inside_annotations"

# 训练配置
training:
  outside_model:
    epochs: 100
    batch_size: 16
    learning_rate: 0.001

# 行为量化配置
behavior:
  individual:
    velocity_threshold: 50     # 速度阈值
    staying_threshold: 100    # 停留阈值
  group:
    density_grid_size: 100    # 密度网格大小
```

### 2. 处理巢外视频（可见光）

```bash
python main.py --mode outside --video <视频路径> --output <输出目录>
```

参数说明：
- `--video`: 输入视频文件路径（支持 MP4、AVI 等格式）
- `--output`: 输出目录，默认为 `output`
- `--show`: 可选，显示结果视频窗口
- `--device`: 可选，运行设备，默认自动选择 CUDA > MPS > CPU
- `--tracker`: 可选，`botsort` 或 `bytetrack`，默认读取配置文件

示例：

```bash
# 处理视频并保存结果
python main.py --mode outside --video data/outside.mp4 --output results

# 处理视频并实时显示
python main.py --mode outside --video data/outside.mp4 --output results --show

# 使用CPU运行
python main.py --mode outside --video data/outside.mp4 --output results --device cpu
```

### 3. 处理巢内视频（红外）

```bash
python main.py --mode inside --video <视频路径> --output <输出目录>
```

示例：

```bash
python main.py --mode inside --video data/inside.mp4 --output results
```

### 4. 多模态同步处理

同时处理巢外和巢内视频，并进行同步分析：

```bash
python main.py --mode multi --video <巢外视频> --video_inside <巢内视频> --output <输出目录>
```

示例：

```bash
python main.py --mode multi \
    --video data/outside.mp4 \
    --video_inside data/inside.mp4 \
    --output results
```

### 5. 数据标注

早期 `main.py --mode annotate` 本地工具不支持头胸腹骨架、统一 JSON 和标注来源门禁，
已停止用于正式数据。巢内外预标注、CVAT 校正、回导与金标准校验流程见：

- [CVAT 姿态标注与回导流程](CVAT姿态标注与回导流程.md)
- [无标注视频标注与评测规范](无标注视频标注与评测规范.md)

### 6. 模型训练

训练入口要求 `dataset_meta.json` 证明标注和 train/val 划分均已就绪。先执行：

```bash
python main.py --mode train --task pose --model <pose权重.pt> --data <data.yaml> --epochs 100 --batch_size -1 --imgsz 640 --device auto --output runs/train --dry_run
```

dry-run 通过后移除 `--dry_run` 启动训练。

主要参数：

- `--model`：与 detect/pose 任务兼容的初始权重；
- `--data`：通过数据门禁的 `data.yaml`；
- `--task`：`detect` 或 `pose`；
- `--epochs`：训练轮数；
- `--batch_size`：批大小，`-1` 表示自动选择；
- `--imgsz`：训练图像尺寸；
- `--device`：`auto`、`cuda:0`、`mps` 或 `cpu`；
- `--lr`：初始学习率。

## 行为量化指标

### 个体行为指标

| 指标名称 | 说明 | 单位 |
|---------|------|------|
| velocity | 运动速度 | 像素/帧 |
| direction | 运动方向 | 度(0-360) |
| duration | 行为持续时间 | 帧 |
| distance | 移动距离 | 像素 |
| direction_changes | 方向变化次数 | 次 |

### 群体行为指标

| 指标名称 | 说明 | 取值范围 |
|---------|------|---------|
| activity_intensity | 活动强度 | 0-1 |
| aggregation_score | 聚集度 | 0-1 |
| density_map | 空间密度分布 | 网格值 |
| bee_count | 蜜蜂数量 | 只 |
| dominant_direction | 主方向 | 度(0-360) |

## 常见问题

### Q1: 报 "ModuleNotFoundError: No module named 'cv2'"

**原因**: 未安装 OpenCV 依赖库

**解决**:
```bash
pip install opencv-python
```

### Q2: 报 "CUDA out of memory"

**原因**: GPU 显存不足

**解决**:
1. 减小批处理大小
2. 使用更小的模型（如 yolov8n）
3. 使用 CPU 运行：`--device cpu`

### Q3: 报 "No module named 'ultralytics'"

**原因**: 未安装 ultralytics 库

**解决**:
```bash
pip install ultralytics
```

### Q4: 视频处理速度慢

**原因**: GPU 未被使用或性能不足

**解决**:
1. 确认 CUDA 可用：`python -c "import torch; print(torch.cuda.is_available())"`
2. 使用视频抽帧处理（如每隔5帧处理1帧）
3. 减小输入图像尺寸

### Q5: 跟踪ID频繁切换

**原因**: 跟踪参数不适合当前场景

**解决**:
调整 `configs/config.yaml` 中的跟踪器参数：
```yaml
tracker:
  max_age: 50        # 增大最大丢失帧数
  min_confidence: 0.2  # 兼容跟踪器的最低检测置信度
```
