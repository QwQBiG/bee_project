# 🐝 蜜蜂数据标注指南

## 一、标注前准备

### 1. 了解两种场景

| 场景 | 图像类型 | 标注重点 |
|------|---------|---------|
| **巢外（Outside）** | 可见光 | 蜜蜂的进出行为、采集行为 |
| **巢内（Inside）** | 红外 | 蜜蜂状态、蜂王识别 |

### 2. 标注类别说明

#### 巢外场景（4类）
- **bee_entering**（进入）：蜜蜂正进入蜂箱
- **bee_exiting**（飞出）：蜜蜂正飞出蜂箱
- **bee_foraging**（采集）：蜜蜂在花上采蜜
- **bee_resting**（休息）：蜜蜂停留在某处不动

#### 巢内场景（4类）
- **bee_normal**（普通）：正常活动的工蜂
- **bee_queen**（蜂王）：体型较大、腹部较长的蜂后
- **bee_working**（工作）：正在工作的蜜蜂
- **bee_moving**（移动）：正在移动的蜜蜂

## 二、标注注意事项

### 📌 基础规则

1. **标注框要准确**：框住整个蜜蜂身体，不要切头切尾
2. **类别要精准**：仔细观察再选择类别
3. **不要遗漏**：画面中所有蜜蜂都要标注
4. **保持一致**：同一个蜜蜂在不同帧保持相同ID

### 📌 巢外标注要点

✅ 正确做法：
- 蜜蜂身体完全在框内
- 进入蜂箱门口的标 entering
- 飞出蜂箱门口的标 exiting
- 在花朵上的标 foraging
- 停在树枝/地面的标 resting

❌ 错误做法：
- 框只框了蜜蜂的翅膀
- 把蝴蝶当成蜜蜂标注
- 远处模糊的小点也标注

### 📌 巢内标注要点

✅ 正确做法：
- 蜂王要仔细辨认（体型最大）
- 正在扇风/搬运的标 working
- 快速移动的标 moving
- 静止不动的标 normal

❌ 错误做法：
- 把所有蜜蜂都标 normal
- 漏标蜂王
- 标注框太大，包含了多个蜜蜂

### 📌 行为标注要点

1. **entering（进入）**：蜜蜂穿过蜂箱入口向内
2. **exiting（离开）**：蜜蜂穿过蜂箱入口向外
3. **foraging（采集）**：蜜蜂停在花朵上
4. **resting（休息）**：静止超过5帧
5. **grooming（梳洗）**：用腿清理身体
6. **trophallaxis（交哺）**：两只蜜蜂互相喂食
7. **wandering（游荡）**：无目的漫游

## 三、推荐标注技术

### 1. 标注工具推荐

| 工具 | 特点 | 适合场景 |
|------|------|---------|
| **LabelImg** | 简单易用 | 初学者、小批量标注 |
| **VGG Image Annotator** | 在线工具 | 多人协作 |
| **CVAT** | 专业级 | 大规模标注、视频标注 |
| **LabelStudio** | 多功能 | 复杂标注任务 |

### 2. 标注流程建议

第一步：抽取关键帧
   ↓
第二步：预标注（使用YOLO自动检测）
   ↓
第三步：人工修正
   ↓
第四步：质量检查
   ↓
第五步：格式转换

### 3. 高效标注技巧

1. **抽帧标注**：不用每一帧都标，每隔5-10帧标一帧
2. **预标注辅助**：先用YOLO模型自动检测，再人工修正
3. **快捷键操作**：记住常用快捷键，提升效率
4. **多人协作**：分工标注，最后统一检查

## 四、标注格式说明

### 支持的格式

| 格式 | 用途 | 扩展名 |
|------|------|--------|
| **YOLO** | 目标检测训练 | .txt |
| **COCO** | 通用格式 | .json |
| **MOT** | 多目标跟踪 | .txt |

### YOLO格式示例

```
# 格式：类别ID 中心点X 中心点Y 宽度 高度（归一化）
0 0.5 0.3 0.1 0.15  # bee_entering
1 0.7 0.6 0.08 0.12  # bee_exiting
```

### 使用标注工具

```bash
# 启动标注模式
python main.py --mode annotate --video data/video.mp4 --output annotations

# 操作说明：
# n - 下一帧
# p - 上一帧  
# s - 保存当前帧标注
# q - 退出
```

## 五、质量控制

### ✅ 检查清单

1. **完整性**：画面中所有可见蜜蜂都标注了吗？
2. **准确性**：类别标注正确吗？
3. **一致性**：同一蜜蜂在连续帧中ID相同吗？
4. **边界框**：框是否准确包围蜜蜂？

### 📊 标注质量指标

| 指标 | 说明 | 目标值 |
|------|------|-------|
| **标注覆盖率** | 标注蜜蜂数/实际蜜蜂数 | ≥95% |
| **类别准确率** | 正确类别数/总标注数 | ≥90% |
| **边界框IoU** | 标注框与真实框重合度 | ≥0.7 |

## 六、常见问题解答

### Q1: 蜜蜂太小看不清怎么办？

答：放大图像仔细看，实在看不清的可以跳过，不要乱标。

### Q2: 一只蜜蜂同时符合多个类别怎么办？

答：选择最主要的行为。比如正在采蜜的蜜蜂，即使在缓慢移动，也标foraging。

### Q3: 如何判断蜂王？

答：蜂王通常比工蜂大，腹部更长更粗，周围常有工蜂围绕。

### Q4: 标注速度太慢怎么办？

答：使用抽帧标注，或者先用预标注工具自动生成标注框，再人工修正。

## 七、实战建议

🌟 新手入门建议：
1. 先从简单的巢外场景开始
2. 标注前先看10分钟视频熟悉蜜蜂行为
3. 每天标注1-2小时，避免疲劳
4. 标注完后自己复查一遍
