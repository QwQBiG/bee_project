## 本轮修复

- YOLO 中心坐标先转换到原图左上角坐标再进行 NMS，修正原来去重使用错误坐标的问题。
- 200/600 数量限制改为在 NMS 后执行，避免重复候选提前占满名额而漏掉其他目标。
- 文件夹任务明确指定巢内或巢外模型；官方路径与指定任务冲突时立即报错。
- 正式 EXE 名称中的任务、队伍 ID 不允许被调试参数改写。
- 修正非正方形输入的 OpenCV 宽高次序，拒绝将姿态模型的关键点当作类别置信度。
- 模型缓存使用相对于配置文件解析的绝对路径，避免不同配置中的同名权重混用。
- 参数错误输出单行状态，结果通过临时文件原子替换，避免失败写入破坏已有结果。
- 拒绝舍入后宽高为零的框；队伍 ID 限定六位 ASCII 数字。
